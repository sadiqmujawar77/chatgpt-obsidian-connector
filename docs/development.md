# Development Guide

This document describes the local development workflow for the
ChatGPT Obsidian Connector.

The project is designed to run locally on Windows with a browser
extension, a Python connector, and an Obsidian vault.

---

## Prerequisites

The current development environment requires:

- Windows
- Python 3.12 or later
- Microsoft Edge or a Chromium-based browser
- Obsidian
- Git

The browser extension uses Manifest V3.
